# Protobuf (`internal/proto/`)

Protocol Buffer service definitions and generated Go stubs for gRPC APIs.

---

## Source definitions

### `internal/proto/sample/v1/sample.proto`

- **Purpose:** gRPC API contract for sample CRUD.
- **Layer / role:** API schema (source of truth).
- **Key definitions:**
  - `service SampleService` — `CreateSample`, `GetSample`, `ListSamples`, `UpdateSample`, `DeleteSample`
  - Messages: `CreateSampleRequest`, `GetSampleRequest`, `ListSamplesRequest`, `UpdateSampleRequest`, `DeleteSampleRequest`, `DeleteSampleResponse`, `SampleResponse`, `ListSamplesResponse`
  - `SampleResponse` includes `google.protobuf.Timestamp` for `created_at` / `updated_at`
- **Dependencies:** `google/protobuf/timestamp.proto`
- **Used by:** `protoc` generation; sample gRPC handler and transport
- **Patterns:** `proto3`; package `sample.v1`; `go_package` → `samplev1`
- **Notes:** Edit this file, then regenerate stubs. Do not edit `*.pb.go` manually.

---

### `internal/proto/healthcheck/v1/healthcheck.proto`

- **Purpose:** gRPC API contract for dependency health reporting.
- **Layer / role:** API schema.
- **Key definitions:**
  - `service HealthcheckService` — `Check(CheckRequest) returns (CheckResponse)`
  - `Dependency` — `name`, `status`, `message`
  - `CheckResponse` — overall `status`, `dependencies` list
- **Dependencies:** None
- **Used by:** Healthcheck gRPC handler and transport
- **Patterns:** Package `healthcheck.v1`; `go_package` → `healthv1`
- **Notes:** Distinct from `grpc.health.v1` standard health service registered in `app/grpc/server.go`.

## Generation workflow

1. Install tools: `protoc`, `protoc-gen-go`, `protoc-gen-go-grpc`
2. Run from repo root:

```bash
make proto
```

or:

```bash
./scripts/generate.sh
```

The Makefile invokes:

```bash
protoc -I internal/proto \
  --go_out=internal/proto --go_opt=module=clean-template/internal/proto \
  --go-grpc_out=internal/proto --go-grpc_opt=module=clean-template/internal/proto \
  internal/proto/sample/v1/sample.proto \
  internal/proto/healthcheck/v1/healthcheck.proto
```

See [root-and-tooling.md](../root-and-tooling.md) for Makefile and script details.
